# Mock Investment Dashboard

A small, browser-only investment simulator for code-review and static-analysis practice. It uses fictional symbols and local demo state only; it is not connected to a brokerage and must never be used with real funds or personal data.

## Run

Open `index.html` in a browser. No build step or external dependencies are required.

## Feature

This change adds a portfolio view and lets a user place simulated market orders against a fictional cash balance.
